# Journal dimension lines

Original vector assets supplied in the user’s Figma design:
https://www.figma.com/design/lmoNXN4R9alKrtGifZGJ7b/three-stacked-goats?node-id=57-9

- `dimension-height.svg`: node 57:7, left height line.
- `dimension-width.svg`: node 57:10, lower width line.

The SVG files are preserved as exported and transformed as whole images to follow the live model. The underlying screenshot in Figma is a placement reference for the existing interactive journal, not a runtime image. Labels use the user-confirmed closed size: 5 inches tall × 4 inches wide.
